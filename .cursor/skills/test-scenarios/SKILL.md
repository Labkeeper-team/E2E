# Test Scenarios

## Общие правила

- Все сценарии лежат в `docs/scenarios`.
- Сценарии для новых пользователей лежат в `docs/scenarios/newUsers`.
- Сценарии для старых пользователей лежат в `docs/scenarios/oldUsers`.
- Каждый сценарий хранится в отдельном Markdown-файле.
- Имена файлов писать по-английски в camelCase, без дефисов и без транслита.
- Заголовок сценария писать по-русски через Markdown-заголовок первого уровня.
- В тексте сценариев использовать слово `пользователь`, а не `человек`.
- Сценарии писать нумерованным списком.
- Название продукта/формата писать как `LaTeX`, не `Latech`.
- Для GPT использовать написание `GPT`.
- Для Markdown использовать написание `Markdown`.

## Формат файла

```markdown
# Название сценария по-русски

1. Пользователь ...
2. Пользователь ...
3. Пользователю ...
```

## New Users

Новые пользовательские сценарии класть в:

`docs/scenarios/newUsers`

Примеры тем:

- новый пользователь в LaTeX редакторе;
- новый пользователь зашел в Markdown редактор;
- новый пользователь сразу зашел в GPT;
- пользователь-физтех смотрит превью лабораторной;
- компиляция Preview LaTeX проекта.

## Old Users

Сценарии для старых пользователей класть в:

`docs/scenarios/oldUsers`

Примеры тем:

- старый пользователь работает со своими проектами;
- старый пользователь открывает превью проект и клонирует его;
- залогиненный пользователь заходит на страницу `/projects`;
- стандартный сценарий использования Markdown-проекта;
- стандартный сценарий использования LaTeX-проекта.

## Стиль сценариев

- Писать просто и последовательно.
- Каждый пункт должен описывать одно действие или один ожидаемый результат.
- Если есть важное состояние пользователя, указывать его явно: `залогиненный пользователь`, `незалогиненный пользователь`.
- Для проверок результата писать отдельные пункты: проект открылся, компиляция прошла, PDF отображается, список проектов виден.
- Не смешивать несколько независимых проверок в один пункт, если они важны для тестирования.

## Типовые формулировки

- `Пользователь заходит на корневую страницу сайта.`
- `Пользователь нажимает кнопку «Мои проекты».`
- `Пользователю открывается список его проектов.`
- `Пользователь нажимает кнопку «Выполнить».`
- `Проект успешно компилируется.`
- `Пользователю показывается информация о том, что нужно залогиниться.`
- `Пользователь регистрируется.`
- `После регистрации пользователь логинится.`
