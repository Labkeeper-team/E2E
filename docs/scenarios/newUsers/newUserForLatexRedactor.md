# Новый пользователь в LaTeX редакторе

1. Пользователь заходит в корень сайта.
2. Пользователь находит раздел LaTeX Editor.
3. Пользователь нажимает кнопку перехода к редактору в разделе LaTeX Editor.
4. Пользователь добавляет произвольный Markdown-сегмент.
5. Пользователь добавляет LaTeX-сегмент.
6. Пользователь нажимает кнопку компиляции.
7. Пользователь повторяет добавление и редактирование сегментов некоторое количество раз.
8. Пользователь снова нажимает кнопку компиляции.
9. Пользователю показывается информация о том, что нужно залогиниться.
10. Пользователь регистрируется одним из доступных способов: через OAuth 2 или через указание явной почты.
11. Пользователю показывается окно о том, что нужно принять политику конфиденциальности, пользователь нажимает кнопку «Принять», после чего окно больше не показывается.
12. После регистрации пользователь логинится.
13. Пользователь видит, что изменения, которые он сделал до регистрации, сохранены в отдельный проект.
14. Пользователь продолжает работать с этим проектом.
15. Пользователь нажимает кнопку компиляции еще несколько раз.
16. Пользователь выходит в список проектов, нажимая кнопку «Мои проекты» или кнопку «Назад».
17. Пользователь нажимает кнопку «Добавить новый проект».
18. Пользователь выбирает тип проекта LaTeX.
19. Пользователю открывается новый проект.
20. Пользователь редактирует новый проект.
21. Пользователь нажимает кнопку «Компиляция».
22. После завершения работы пользователь нажимает кнопку выхода из аккаунта.
23. Пользователь разлогинивается.
24. Пользователь заново заходит на сайт.
25. Пользователь заново логинится.
26. Пользователю показывается последний проект, с которым он работал.
