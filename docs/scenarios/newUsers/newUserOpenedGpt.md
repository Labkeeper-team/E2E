# Новый пользователь сразу зашел в GPT

1. Новый пользователь заходит на корневую страницу сайта.
2. Новый пользователь выбирает раздел «Запросы к GPT».
3. Новый пользователь нажимает кнопку перехода к проекту.
4. Пользователю открывается редактор.
5. В редакторе сразу отображается плашка с запросами к GPT.
6. Пользователь пишет простой запрос к GPT.
7. Пользователю генерируется текст по запросу.
8. Пользователь делает еще несколько запросов к GPT.
9. Пользователь сопровождает запросы несколькими компиляциями.
10. Пользователю показывается плашка о том, что нужно зарегистрироваться.
11. Пользователь регистрируется.
12. После регистрации пользователь логинится.
13. Пользователь видит, что его проекты остались на месте.
