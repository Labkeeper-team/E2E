# Компиляция Preview LaTeX проекта

1. Незалогиненный пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает «Примеры проектов».
3. Пользователь выбирает какой-нибудь LaTeX-проект.
4. Пользователь нажимает на выбранный LaTeX-проект.
5. Пользователь переходит в превью этого проекта.
6. Пользователь нажимает кнопку «Выполнить».
7. Пользователь видит, что проект компилируется.
8. Пользователю отображается скомпилированный LaTeX-документ.
9. Пользователь нажимает кнопку «Выполнить» еще несколько раз.
10. Пользователь видит, что LaTeX-документ продолжает успешно компилироваться и отображаться.
11. Пользователь нажимает кнопку «Клонировать».
12. Пользователю показывается информация о том, что для клонирования нужно залогиниться.
13. После нескольких запусков компиляции пользователю также показывается информация о том, что нужно залогиниться.
14. Пользователь регистрируется.
15. Пользователю показывается окно о том, что нужно принять политику конфиденциальности, пользователь нажимает кнопку «Принять», после чего окно больше не показывается.
16. После регистрации пользователь логинится.
17. Пользователь возвращается к этому же Preview LaTeX проекту.
18. Пользователь нажимает кнопку «Клонировать».
19. Проект успешно клонируется.
20. У пользователя открывается собственный новый проект, созданный из склонированного Preview LaTeX проекта.
21. Пользователь нажимает кнопку «Выполнить» в своем новом проекте.
22. Склонированный проект успешно компилируется.
23. Пользователь выходит в список своих проектов.
24. Пользователь видит в списке проектов этот склонированный проект.
