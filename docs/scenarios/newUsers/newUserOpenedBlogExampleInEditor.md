# Незалогиненный пользователь открывает пример из статьи

1. Незалогиненный пользователь заходит на корневую страницу сайта.
2. Пользователь находит блок «База знаний».
3. Пользователь нажимает кнопку «Все статьи».
4. Пользователю открывается блог.
5. Пользователь открывает статью «Расчет и оформление доверительных интервалов (погрешности Стьюдента)».
6. Пользователь нажимает кнопку «Просмотреть пример» с подписью «в редакторе».
7. Пользователю открывается редактор.
8. Пользователь видит, что проект имеет тип LaTeX.
9. Пользователь видит карточки заголовка и футера документа.
10. Пользователь видит сегмент «Вычисление» с пятью измерениями длины: 9.8, 9.8, 10.2, 10.6 и 10.6.
11. Пользователь видит LaTeX-сегмент с текстом примера из этой статьи.
12. Сразу после открытия редактора проект начинает собираться.
13. Если в результате компиляции пользователю показывается плашка, что надо залогиниться, сценарий заканчивается.
14. Проект успешно выполняется.
15. Пользователю показывается PDF.
16. В PDF виден посчитанный доверительный интервал по этим пяти измерениям.
17. Пользователь меняет в сегменте «Вычисление» одно измерение.
18. Пользователь нажимает кнопку «Выполнить».
19. Проект успешно выполняется.
20. В PDF виден пересчитанный результат.
21. Пользователь возвращается в блог.
22. Пользователь открывает статью «Съезжает верстка в Word при написании диплома? Переходим на легковесную разметку».
23. Пользователь нажимает кнопку «Просмотреть пример» с подписью «в редакторе».
24. Пользователю снова открывается редактор.
25. Пользователь видит Markdown-сегмент с заголовком «Введение».
26. Пользователь видит LaTeX-сегмент с примером этой статьи.
27. Сегмента с пятью измерениями длины в проекте нет.
28. Сразу после открытия редактора проект начинает собираться.
29. Проект успешно выполняется.
30. Пользователю показывается PDF.
31. В PDF виден текст «Введение» из примера второй статьи.
