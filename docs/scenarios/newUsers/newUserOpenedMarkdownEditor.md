# Новый пользователь зашел в Markdown редактор

1. Пользователь заходит на корневую страницу сайта.
2. Пользователь выбирает раздел Markdown Editor.
3. Пользователь нажимает кнопку «Перейти к редактору».
4. Пользователю открывается Markdown-редактор.
5. Пользователь добавляет произвольный Markdown-текст.
6. Пользователь видит, что результат рендеринга доступен сразу, без необходимости запускать компиляцию.
7. Пользователь добавляет вычисление.
8. Пользователь видит, что для вычисления требуется компиляция.
9. Пользователь запускает компиляцию.
10. Пользователь пробует добавить картинку с помощью Ctrl-V.
11. Пользователю показывается информация о том, что для этого нужно авторизоваться.
12. Пользователь добавляет пример из закладки с примерами.
13. Пользователь запускает компиляцию.
14. Пользователь видит, что пример корректно отрендерился после компиляции.
15. Пользователю предлагают зарегистрироваться.
16. Пользователь регистрируется.
17. Пользователю показывается окно о том, что нужно принять политику конфиденциальности, пользователь нажимает кнопку «Принять», после чего окно больше не показывается.
18. После регистрации пользователь заново логинится.
19. Пользователь видит, что код, который он редактировал, появился в его новом проекте.
