# Пользователь-физтех зашел смотреть превью лабу

1. Пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает «Примеры проектов».
3. Пользователь выбирает какую-нибудь лабораторную работу.
4. Пользователю открывается превью-проект лабораторной работы.
5. Превью-проект уже скомпилирован.
6. В превью-проекте присутствуют все графики.
7. В превью-проекте присутствуют все вычисления.
8. Пользователь нажимает «Выполнить», чтобы запустить компиляцию.
9. Пользователь нажимает кнопку «Выполнить» несколько раз.
10. Через некоторое время пользователю предлагают зарегистрироваться.
11. Пользователь регистрируется.
12. Пользователю показывается окно о том, что нужно принять политику конфиденциальности, пользователь нажимает кнопку «Принять», после чего окно больше не показывается.
13. После регистрации пользователь логинится.
14. После логина пользователь возвращается обратно на этот же публичный проект.
15. У пользователя появляется кнопка, с помощью которой он может склонировать проект.
16. Пользователь клонирует проект.
17. Проект в полной мере появляется у пользователя в библиотеке.
18. Пользователь запускает склонированный проект.
19. Склонированный проект успешно отрабатывает.
