# Залогиненный пользователь добавляет схемы в проект

1. Залогиненный пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает кнопку «Мои проекты».
3. Пользователю открывается список его проектов.
4. Пользователь нажимает кнопку «Добавить».
5. Пользователь вводит имя проекта.
6. Пользователь выбирает тип проекта Markdown.
7. Пользователь нажимает «Создать».
8. Пользователю открывается новый Markdown-проект.
9. Пользователь в меню «Добавить» видит пункты Mermaid, PlantUML и draw.io.
10. Пользователь добавляет сегмент «Вычисление».
11. Пользователь пишет в сегменте «Вычисление» строку `a = 1`.
12. Пользователь добавляет сегмент «Маркдаун».
13. Пользователь пишет в сегменте «Маркдаун» предложение «Схемы ниже».
14. Пользователь добавляет сегмент Mermaid.
15. Пользователь пишет в сегменте Mermaid схему `flowchart LR` со стрелкой от `A[Старт]` к `B[Готово]`.
16. Пользователь добавляет сегмент PlantUML.
17. Пользователь пишет в сегменте PlantUML строку `Alice -> Bob: привет`.
18. Пользователь добавляет сегмент draw.io.
19. Пользователь вставляет в сегмент draw.io XML с корнем `mxGraphModel` и блоком, на котором написано «Схема».
20. Пользователь нажимает кнопку «Выполнить».
21. Проект успешно выполняется.
22. В колонке «Итоговый документ» пользователь видит результат `a = 1`.
23. Пользователь видит текст «Схемы ниже».
24. Пользователь видит нарисованную схему Mermaid со «Старт» и «Готово».
25. Пользователь видит нарисованную схему PlantUML с сообщением «привет».
26. Пользователь видит нарисованную схему draw.io с подписью «Схема».
27. Пользователь заменяет текст сегмента Mermaid на `не схема`.
28. Пользователь нажимает кнопку «Выполнить».
29. Проект успешно выполняется.
30. На месте схемы Mermaid пользователь видит «Схему не удалось нарисовать».
31. Текст `не схема` остаётся в сегменте Mermaid.
32. Схемы PlantUML и draw.io по-прежнему нарисованы.
33. Пользователь заменяет XML сегмента draw.io на текст `не схема`.
34. Пользователь нажимает кнопку «Выполнить».
35. На месте схемы draw.io пользователь видит «Схему не удалось нарисовать».
36. Пользователь видит текст «Это не XML схемы draw.io: нужен mxfile или mxGraphModel».
37. Пользователь возвращает в сегмент draw.io прежний XML.
38. Пользователь нажимает кнопку «Выполнить».
39. Схема draw.io снова нарисована.
40. Пользователь возвращается в список своих проектов.
41. Пользователь нажимает кнопку «Добавить».
42. Пользователь вводит имя проекта.
43. Пользователь выбирает тип проекта LaTeX.
44. Пользователь нажимает «Создать».
45. Пользователю открывается новый LaTeX-проект.
46. Пользователь добавляет сегмент Mermaid с той же схемой `flowchart LR` от `A[Старт]` к `B[Готово]`.
47. Пользователь нажимает кнопку «Выполнить».
48. Проект успешно выполняется.
49. Пользователю показывается PDF.
50. В PDF видна нарисованная схема со «Старт» и «Готово».
