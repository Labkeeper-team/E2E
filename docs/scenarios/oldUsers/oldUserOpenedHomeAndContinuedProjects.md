# Старый пользователь зашел на главную страницу и пошел работать со своими проектами

1. Пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает кнопку «Перейти в редактор».
3. Пользователю показывается последний проект, который он редактировал.
4. Пользователь нажимает в меню кнопку «Мои проекты» или стрелочку слева сверху.
5. Пользователь переходит в список своих проектов.
6. Пользователь выбирает любой проект из списка.
7. Пользователь заходит в выбранный проект.
8. Пользователь редактирует выбранный проект.
9. Пользователь возвращается в список своих проектов.
10. Пользователь нажимает кнопку «Добавить».
11. Пользователь создает новый проект.
12. Пользователю открывается новый проект.
13. Пользователь редактирует новый проект.
14. Изменения в новом проекте сохраняются.
15. Пользователь изменяет содержимое проекта.
16. Пользователь нажимает кнопку «Рефреш».
17. Пользователь видит, что содержимое проекта сохранилось.
18. Пользователь возвращается в список проектов.
19. Пользователь нажимает кнопку «Удалить» у выбранного проекта.
20. Проект удаляется из списка проектов пользователя.
