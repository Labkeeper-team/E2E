# Залогиненный пользователь собирает документ в агентском режиме

1. Залогиненный пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает кнопку «Мои проекты».
3. Пользователю открывается список его проектов.
4. Пользователь открывает свой LaTeX-проект, в котором ещё не было запросов к агенту.
5. Пользователь открывает вкладку «Агент».
6. Пользователь видит панель «Помощь».
7. Если панель «Помощь» свёрнута, пользователь разворачивает её.
8. На первом слайде пользователь видит заголовок «Создайте ваш первый документ».
9. Пользователь нажимает кнопку «Агентский режим» рядом с вкладками «Агент» и «Итоговый документ».
10. В адресе страницы появляется `/agent`.
11. Слева пользователь видит чат агента, справа — колонку «Итоговый документ».
12. Пользователь открывает «Настройки агента».
13. Пользователь видит размер контекста: 100k, 200k и 300k.
14. Пользователь видит максимум итераций: 200, 500 и 1000.
15. Пользователь видит включённую галочку «Разрешить агенту компилировать».
16. Пользователь нажимает «Закрыть настройки».
17. Если появляется окно «Передача данных в DeepSeek», пользователь нажимает «Продолжить».
18. Пользователь пишет запрос дописать в документ короткий раздел и собрать его.
19. Пользователь нажимает «Отправить».
20. Пока агент работает, пользователь видит, что документ нельзя редактировать.
21. Пользователь видит шаги агента: обращение к модели, правки и завершение работы.
22. В шагах агента пользователь видит сборку документа.
23. Справа открыт итоговый документ.
24. Итоговый документ прокручивается к последнему изменению.
25. Пользователь видит правки с кнопками «Принять» и «Отклонить».
26. Пользователь видит счётчик «Всего N изменений».
27. Пользователь нажимает «Принять все».
28. Принятые правки остаются в документе.
29. Пользователь набирает в поле запроса несколько слов.
30. Пользователь нажимает «Загрузить файл» и загружает картинку.
31. Набранные слова остаются в поле.
32. В конец поля дописывается «Добавь в документ файл {имя}, который я загрузил».
33. Загруженный файл виден над полем запроса.
34. Пользователь отправляет этот запрос.
35. Шаги предыдущего запроса сворачиваются.
36. Пользователь разворачивает шаги предыдущего запроса кнопкой «Шаги агента».
37. Пользователь нажимает «Очистить историю».
38. Пользователю показывается вопрос «Вы уверены, что хотите очистить историю?».
39. Пользователь видит галочку «Больше не спрашивать».
40. Пользователь отмечает «Больше не спрашивать».
41. Пользователь нажимает «Да».
42. История диалога очищается.
43. Пользователь отправляет короткий новый запрос и дожидается ответа.
44. Пользователь снова нажимает «Очистить историю».
45. Окно подтверждения не появляется.
46. История диалога очищается сразу.
47. Пользователь нажимает «Открыть полный редактор кода».
48. Окончание `/agent` пропадает из адреса.
49. Пользователь видит в сегментах проекта правки, которые он принял.
