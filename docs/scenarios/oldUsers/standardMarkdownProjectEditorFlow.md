# Стандартный сценарий использования редактора в Markdown проектах

1. Залогиненный пользователь заходит на корневую страницу сайта.
2. Пользователь видит кнопку «Мои проекты».
3. Пользователь нажимает кнопку «Мои проекты».
4. Пользователю открывается список его проектов.
5. Пользователь выбирает какой-нибудь свой Markdown-проект.
6. Пользователь открывает выбранный Markdown-проект.
7. Пользователь нажимает кнопку с примерами в виде книжечки с закладкой.
8. Пользователь выбирает любой пример из списка.
9. Выбранный пример успешно добавляется в Markdown-проект.
10. Пользователь делает какой-нибудь запрос к GPT.
11. Результат запроса к GPT успешно добавляется в Markdown-проект.
12. Пользователь добавляет стандартные сегменты.
13. Все стандартные сегменты успешно добавляются в Markdown-проект.
14. Пользователь копирует очень большой текст в Markdown-сегмент.
15. Очень большой текст успешно добавляется в Markdown-сегмент.
16. Пользователь создает несколько новых сегментов.
17. Пользователь нажимает Ctrl-Z, чтобы отменить действие.
18. Отмена действия отрабатывает стабильно.
19. Пользователь нажимает Ctrl-Y, чтобы вернуть действие.
20. Возврат действия отрабатывает стабильно.
21. Пользователь в каком-нибудь сегменте зажимает клавишу, чтобы символы появлялись непрерывно.
22. Непрерывный ввод символов не вызывает лагов.
23. Пользователь добавляет строку в очень длинный сегмент.
24. Пользователь нажимает Ctrl-Z.
25. Добавленная строка успешно отменяется.
26. Пользователь добавляет новый сегмент.
27. Пользователь нажимает Ctrl-Z.
28. Добавленный сегмент удаляется.
