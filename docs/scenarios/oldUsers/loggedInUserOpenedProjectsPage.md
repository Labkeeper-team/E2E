# Залогиненный пользователь зашел на страницу с проектами

1. Залогиненный пользователь сразу заходит на страницу `/projects`.
2. Пользователю сразу отображается список его проектов.
3. Пользователь успешно видит свой список проектов.
4. Если у пользователя протухла сессия, ему отображается `project default`.
5. В этом случае пользователю открывается чистый редактор.
6. В чистом редакторе пользователь логинится.
7. После логина пользователь видит свой список проектов.
