# Залогиненный пользователь пользуется сочетаниями клавиш в проекте

1. Залогиненный пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает кнопку «Мои проекты».
3. Пользователю открывается список его проектов.
4. Пользователь открывает свой LaTeX-проект, в котором одно и то же слово есть в двух разных сегментах.
5. Пользователь открывает меню по иконке книжки с закладкой.
6. Пользователь нажимает «Сочетания клавиш».
7. Пользователь видит заголовок «Сочетания клавиш».
8. Пользователь видит в списке поиск, сборку проекта и переход между сегментами.
9. Пользователь нажимает Esc.
10. Плашка сочетаний закрывается.
11. Пользователь нажимает Ctrl+F.
12. Открывается поиск, курсор стоит в поле «Введите текст для поиска...».
13. Пользователь вводит слово, которое есть в двух сегментах.
14. Пользователь нажимает F3.
15. Редактор переходит к следующему совпадению.
16. Пользователь нажимает Shift+F3.
17. Редактор переходит к предыдущему совпадению.
18. Пользователь нажимает Esc.
19. Поиск закрывается.
20. Пользователь нажимает Ctrl+Shift+E.
21. Пользователю открывается файловый менеджер.
22. Пользователь нажимает Ctrl+Shift+E ещё раз.
23. Файловый менеджер скрывается.
24. Пользователь нажимает Alt+↓.
25. Курсор переходит в следующий сегмент.
26. Пользователь нажимает Alt+↑.
27. Курсор переходит в предыдущий сегмент.
28. Пользователь нажимает Ctrl+Shift+L.
29. Под текущим сегментом появляется новый LaTeX-сегмент, курсор стоит в нём.
30. Пользователь пишет в новом сегменте строку обычного текста.
31. Пользователь нажимает Ctrl+Enter.
32. Проект успешно выполняется.
33. Пользователю показывается PDF.
34. Пользователь дописывает в тот же сегмент ещё одно слово.
35. Пользователь нажимает Ctrl+S.
36. Проект собирается снова.
37. В PDF виден дописанный текст.
38. Пользователь ставит курсор на строку в сегменте.
39. Пользователь нажимает Ctrl+Alt+J.
40. PDF пролистывается к этой строке.
41. Пользователь кликает место в PDF.
42. Пользователь нажимает Ctrl+Alt+K.
43. Сегменты пролистываются к соответствующему месту в коде.
44. Пользователь добавляет в LaTeX-сегмент команду `\test`.
45. Пользователь нажимает Ctrl+Enter.
46. PDF остаётся на экране.
47. Пользователь видит список проблем с этой ошибкой.
48. Пользователь нажимает Ctrl+..
49. Открывается вкладка «Агент».
50. В поле запроса стоит текст «Исправь ошибки компиляции:», курсор в конце этого текста.
51. Пользователь нажимает Ctrl+Alt+P.
52. Открывается колонка «Итоговый документ».
53. Пользователь убирает команду `\test` из сегмента.
54. Пользователь нажимает Ctrl+Enter.
55. PDF успешно собирается.
56. Список проблем пуст.
57. Пользователь делает в сегменте две правки подряд.
58. Пользователь нажимает Ctrl+Z.
59. Последняя правка отменяется.
60. Пользователь нажимает Ctrl+Z ещё раз.
61. Отменяется и предыдущая правка.
62. Пользователь нажимает Ctrl+Y.
63. Первая отменённая правка возвращается.
64. Пользователь нажимает Ctrl+Y ещё раз.
65. Вторая отменённая правка тоже возвращается.
