# Старый пользователь зашел на главную страницу, открыл превью проект и склонировал его

1. Пользователь заходит на корневую страницу сайта.
2. Пользователь нажимает «Примеры проектов».
3. Пользователю открывается плашка с примерами проектов.
4. Пользователь выбирает какой-нибудь проект из списка примеров.
5. Пользователь открывает выбранный проект.
6. Пользователю открывается превью проекта.
7. Пользователь нажимает кнопку «Выполнить».
8. Проект успешно компилируется.
9. Пользователь видит результат компиляции проекта.
10. Пользователь нажимает кнопку «Клонировать».
11. Проект успешно клонируется пользователю.
12. Сценарий обязательно проверяется на Markdown-проектах.
13. Сценарий обязательно проверяется на LaTeX-проектах.
14. Для проверки Markdown-проекта пользователь может выбрать какую-нибудь лабораторную работу.
15. Для проверки LaTeX-проекта пользователь может выбрать какой-нибудь диплом или резюме.
