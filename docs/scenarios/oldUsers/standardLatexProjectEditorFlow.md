# Стандартный сценарий использования LaTeX редактора

1. Пользователь заходит на сайт.
2. Пользователь заходит в «Мои проекты».
3. Пользователь выбирает какой-нибудь LaTeX-проект.
4. Пользователь открывает выбранный LaTeX-проект.
5. Если в проекте нет сегментов, пользователь добавляет LaTeX-сегмент.
6. Пользователю отображаются header и footer для LaTeX-сегмента.
7. Пользователь нажимает на header LaTeX-сегмента.
8. Header превращается в новый сегмент.
9. Пользователь нажимает на footer LaTeX-сегмента.
10. Footer превращается в новый сегмент.
11. Пользователь открывает файловый менеджер в проекте.
12. Пользователь нажимает «Создать файл».
13. Файл успешно создается.
14. Пользователь редактирует название файла.
15. Название файла успешно сохраняется.
16. Пользователь нажимает на файл.
17. Открывается файловый редактор.
18. Файловый редактор позволяет редактировать текст файла.
19. В файлах с расширением `.tex` отображается правильная подсветка кода LaTeX.
20. Пользователь создает папку.
21. Папка успешно добавляется в файловый менеджер.
22. Пользователь создает файл внутри этой папки.
23. Файл успешно создается внутри папки.
24. Пользователь перетаскивает файл в файловый менеджер.
25. Перетащенный файл добавляется в проект.
26. Пользователь переименовывает папку, в которой уже существуют файлы.
27. Папка успешно переименовывается.
28. Пользователь удаляет папку, в которой уже существуют файлы.
29. Папка успешно удаляется вместе с файлами внутри нее.
30. Пользователь нажимает кнопку компиляции.
31. Пользователю компилируется PDF.
32. Пользователь добавляет в LaTeX-код простую ошибку, например несуществующий оператор `\test`.
33. Пользователь нажимает кнопку компиляции.
34. PDF все равно компилируется и отображается.
35. Пользователю отображается вкладка с ошибками.
36. Во вкладке с ошибками показывается, какая ошибка произошла.
37. Пользователь убирает ошибку из LaTeX-кода.
38. Пользователь нажимает кнопку компиляции.
39. PDF успешно компилируется без ошибок.
40. Пользователь выделяет строку в исходном тексте в каком-нибудь сегменте.
41. Пользователь нажимает стрелочку для перехода из исходного текста в PDF.
42. PDF пролистывается к соответствующему месту.
43. Пользователь выделяет место в PDF.
44. Пользователь нажимает стрелочку для перехода из PDF в исходный текст.
45. Исходные сегменты пролистываются до соответствующего места.
